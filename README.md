# codealpha_musicplayer
This project involves the development of a production-grade, interactive audio player featuring a sleek, modern dark-mode aesthetic enriched with subtle glassmorphism and vibrant accent colors. Built entirely with vanilla web technologies, the application deeply integrates with the native HTML5 Audio API to deliver a seamless, high-fidelity listening experience. Core functionalities include comprehensive audio controls (play, pause, next, previous), a dynamically updating draggable progress bar, and volume slider controls that respond precisely to user interactions. The interface actively displays real-time track metadata, including the song title, artist name, and central album art that smoothly rotates in synchronization with the active playback state. A standout feature is the integrated dynamic playlist equipped with an autoplay protocol, ensuring the automated, gapless transition of audio tracks once a song concludes. Building this complex, multi-state application required meticulous synchronization between visual DOM elements and background audio events, serving as excellent practical exposure to event-driven programming and asynchronous media handling.
